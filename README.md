# 멍냥백서

강아지·고양이 보호자를 위한 웹앱. 기본 결과는 무료, 심층 리포트는 1,000원.

| 서비스 | 무료 | 1,000원 심층 리포트 |
| --- | --- | --- |
| 성격유형 테스트 (멍BTI·냥BTI) | 유형, 특징, 성향 그래프 | 보호자 궁합, 찰떡/조심할 친구, 놀이 처방, 스트레스 신호, 훈련 팁 |
| 오늘의 운세 | 총운 점수, 행운의 간식·색·아이템 | 세부 운, 주간 흐름, 이달의 행운의 날 (그 달 말까지 매일 열림) |
| 사주 | 일간(타고난 기질), 띠, 세 기둥 | 오행 분포, 올해·내년 총운, 보호자와의 인연, 기운 보완법 |
| 관상 | 관상 유형, 눈 풀이 | AI가 올린 사진을 직접 보고 쓰는 풀이 (첫인상, 부위별 풀이, 3대 복, 전생, 보호자에게 한마디) |
| 사람 나이 계산기 | 전부 무료 (건강 리포트로 연결) | — |
| 건강 리포트 | 생활 건강 점수, 체형, 생애주기 | 권장 칼로리·급여량, 음수량, 검진 일정, 주의 신호, 체크리스트 |

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

`.env.local`에서 `PAYMENT_MODE=mock`으로 두면 토스 없이 "테스트 결제" 버튼으로 전체 흐름을 볼 수 있습니다(개발 환경 전용, 프로덕션에서는 무시).

## 결제 (토스페이먼츠 결제위젯)

1. 결과 화면의 잠긴 영역 → `/pay` 에서 결제위젯으로 결제
2. 토스가 `/pay/success`로 돌려보내면 서버(`/api/pay/confirm`)가 **1,000원 고정 금액**으로 결제 승인 API 호출
3. 승인되면 서버가 "서비스 + 입력값"에 묶인 서명 토큰(HMAC)을 발급, 브라우저 `localStorage`에 저장
4. 심층 리포트 내용은 `/api/premium`이 토큰을 검증한 뒤에만 내려줌 (유료 내용은 브라우저 코드에 들어 있지 않음)

`.env.example`의 키는 토스페이먼츠 문서의 공개 테스트 키입니다. 실결제 전환 시 필요한 것:

- 사업자등록 + 통신판매업 신고, 토스페이먼츠 가맹 계약
- `TOSS_CLIENT_KEY`(`live_gck_…`), `TOSS_SECRET_KEY`(`live_gsk_…`) — **결제위젯 연동 키**여야 합니다(API 개별 연동 키 `ck_`/`sk_` 아님)
- `UNLOCK_SECRET`을 무작위 값으로 설정 (`openssl rand -hex 32`)
- 푸터의 사업자 정보, `/legal/*`의 약관·환불정책 문의처 채우기 (현재 초안)

DB와 회원가입이 없어서, 결제 기록은 토스 상점관리자에서 확인하고 열람 권한은 결제한 브라우저에만 남습니다.

## AI 사진 관상 풀이

- 관상 입력 화면에서 사진을 고르면 브라우저에서 768px로 줄여 **이 기기에만** 보관합니다. 결제 전에는 서버로 보내지 않습니다.
- 결제 후 `/api/premium`이 사진을 Claude API(`lib/premium/face-ai.ts`)로 보내 풀이를 만들고, 결과는 기기에 보관해 다시 열 때 재생성하지 않습니다.
- 결제는 사진 지문에 묶여 있어 다른 사진으로 바꿔 요청할 수 없고, 같은 결제로는 서버 인스턴스당 4회까지만 AI를 호출합니다.
- `ANTHROPIC_API_KEY`가 없거나 AI 호출이 실패하면 사진 없이 만드는 기본 풀이를 대신 보여주고 다시 시도 버튼을 띄웁니다.
- 사진은 서버에 저장하지 않으므로, 공유 링크를 받은 사람에게는 사진이 보이지 않습니다.

## 카카오톡 공유

- 결과 링크마다 미리보기 이미지(`/api/og`)와 제목이 달라서, 카톡 대화방에 링크만 붙여도 결과 카드가 보입니다.
- `NEXT_PUBLIC_KAKAO_JS_KEY`를 넣으면 카카오 SDK의 카드형 공유를 씁니다(카카오 개발자 콘솔에 사이트 도메인 등록 필요). 없으면 휴대폰 기본 공유 시트 / 링크 복사로 동작합니다.
- 배포 후 `NEXT_PUBLIC_SITE_URL`을 실제 도메인으로 설정하세요.

## 구조

- `lib/engines/*` — 무료 결과 계산, `lib/premium/*` — 유료 결과 계산(서버 전용)
- `lib/products.ts` — 서비스 목록, 가격, 잠금 영역 문구, 사이트 이름
- `lib/token.ts`, `lib/toss.ts` — 잠금 해제 토큰, 토스 결제 승인
- `app/r/[product]` — 결과 화면, `app/pay` — 결제
